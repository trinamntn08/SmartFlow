# Task handoff: S1 modular scene and camera

## Objective and scope

Integrate reviewed legacy scene/controller behavior into the native scene-3d
extension while keeping the platform independent of 3D. This checkpoint covers
scene snapshots, camera navigation and selection. Object editing follows in S2.

## Current state

SceneViewer composes independent model, camera and renderer modules. Added pan,
cursor-anchored zoom and orthographic axis views. Picking uses nearest triangle
intersection. Stable branch-qualified IDs preserve selection across recomputation
and reordering. Transform output records transient provenance for later editing.

Copied five licensed plane/ray/intersection source/header files and two original
MIT notices from legacy commit `d6f457e8415445d00eaf7e9fbf9e5047768ea637`.
The manifest records original hashes; Intersection.cpp has one documented local
correctness patch. CAD pan is an attributed adaptation. Legacy scene layers are
behavior references only; the old checkout remains unchanged.
